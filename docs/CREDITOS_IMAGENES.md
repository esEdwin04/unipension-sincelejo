# Créditos de las imágenes

Las fotografías de `client/public/img/pensiones/` se descargaron de [Unsplash](https://unsplash.com) con su enlace oficial de descarga.
Se publican bajo la [Licencia de Unsplash](https://unsplash.com/license): uso gratuito, comercial o no comercial, sin necesidad de permiso.
No se usaron fotos de Unsplash+ (de pago).

Se ilustran las pensiones **de demostración**: no son fotos de pensiones reales de Sincelejo. Cuando haya propietarios reales, cada uno sube sus propias fotos desde el editor.

Formato: WebP de 1000 × 700 px, entre 44 y 121 KB cada una (la meta de la actividad F3 es ≤ 200 KB).
